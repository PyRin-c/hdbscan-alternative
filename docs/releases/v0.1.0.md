# hdbscan-alternative v0.1.0 プレビュー

HDBSCAN の独立 Rust 実装の初回プレビューです。Python で学習・予測・枝検出を試せる Wheel と、Windows アプリから学習や予測を呼び出せる C ABI を配布します。

| 配布物 | 対象 |
| --- | --- |
| `hdbscan_alternative-0.1.0-cp*-win_amd64.whl` | Windows x64、CPython 3.10〜3.15 |
| `hdbscan_alternative-0.1.0-cp*-manylinux_2_34_x86_64.whl` | Linux x86-64、glibc 2.34 以上、CPython 3.10〜3.15 |
| `hdbscan-alternative-cabi-0.1.0-win-x64.zip` | Windows x64。DLL、MSVC 用ライブラリ、ヘッダー、学習サンプル |
| `SHA256SUMS` | 配布物の SHA-256 チェックサム |

OS と CPython のバージョンに合う Wheel をダウンロードします。Windows x64・CPython 3.13 での例です。

```powershell
py -3.13 -m pip install ./hdbscan_alternative-0.1.0-cp313-cp313-win_amd64.whl
```

```python
from hdbscan_alternative import HDBSCAN

labels = HDBSCAN(min_cluster_size=2, min_samples=1).fit_predict(
    [[0.0], [1.0], [5.0], [6.0]]
)
```

数値照合の基準は、環境を固定した上流 `hdbscan 0.8.44` の公開 Wheel です。Python の予測・枝検出は Euclidean、Manhattan、Minkowski、Chebyshev の密な特徴量を対象とします。C ABI の予測・枝検出は Euclidean と Manhattan に対応します。追加の Ball-tree 距離での予測・枝検出、キャッシュの `tree` と `dist_metric`、`HDBSCAN` の重み付き代表点 API は今後の対応対象です。[検証記録](https://github.com/PyRin-c/hdbscan-alternative/blob/v0.1.0/reference/implementation_status.md)
